<objective>
## Goal
Complete federated scope ingestion: add the two missing sources — **bbscope v2** (authenticated, richer per-program scopes incl. Intigriti OOS) and **projectdiscovery** (VDP layer) — alongside the existing arkadiyt baseline, then drive all three on a periodic **Hatchet scheduled poll task** that commits atomically and emits scope-diff events. Reconcile the pre-existing (v5-carryover) scope code against the custom-PG schema 01-01 rebuilt.

## Purpose
Federated scope ingestion is the data foundation for the whole hunt pipeline — recon/scan/validate only run against in-scope assets carrying source + scope-JWT provenance. arkadiyt alone is the unauthenticated baseline; bbscope adds authenticated depth (and OOS exclusions, which prevent out-of-scope submissions), projectdiscovery adds VDP coverage. Periodic polling keeps scope fresh and produces the diff events that 01-05 will turn into notifications.

## Output
- `integrations/bbscope.py` — bbscope v2 CLI client (`poll`/`db` subcommands)
- `integrations/projectdiscovery.py` — VDP `dist/data.json` client
- `ingest_service.py` — `ingest_bbscope_all` + `ingest_projectdiscovery_all` reusing the federation upsert path
- `workflows/tasks.py` + `worker.py` — `scope_poll` scheduled Hatchet task driving all three sources
- `tests/test_scope_federation.py` — parse + idempotency + reconcile coverage
</objective>
