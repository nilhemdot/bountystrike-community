<objective>
## Goal
Close the parked Phase-1 deploy gates against a LOCAL Docker stack: bake the two
runtime binaries the live paths need (bbscope + chromium) into the images, run the
smokes that prior plans (01-04/05/06/07) could only stub, and finish repo hygiene
(repo-wide CRLF→LF + `.gitattributes`). This makes the Community Edition actually
*run* end-to-end, not just pass offline unit tests.

## Purpose
Plans 01-04..01-07 each shipped code verified by unit tests but deferred the LIVE
path to "the installer / a deploy gate" because they lacked an in-container bbscope
binary, chromium for the XSS oracle, a registered worker, or a real webhook sink.
01-08 made the stack installable; 01-09 proves it works. The deterministic verifier
moat (PROJECT core value) is only credible if XSS validation actually runs chromium
in-container and produces a real evidence artifact. This is the last *engineering*
plan in Phase 1; 01-10 (public AGPLv3 release) is pure release mechanics.

## Output
- `infra/docker/Dockerfile.control-plane` — chromium + Playwright deps baked (worker
  runs the XSS oracle); bbscope binary on PATH (scope_poll live path)
- `infra/docker/Dockerfile.recon` — recon binaries confirmed present (subfinder/httpx/
  katana) for the recon→scan smoke
- `.gitattributes` (new) + repo-wide CRLF→LF normalization of tracked text files
- `scripts/live_smoke.sh` (new) — drives the local deploy-gate smokes, captures results
- `01-09-SUMMARY.md`
</objective>

```gherkin

```

