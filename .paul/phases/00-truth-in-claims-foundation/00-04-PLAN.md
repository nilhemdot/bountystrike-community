<objective>
## Goal
Stamp every eligible source file in the repository with the correct SPDX-License-Identifier comment header (derived from the 3-root license split established in 00-02), and enforce in CI that community/core packages never import from the enterprise/proprietary package, preventing license contamination.

## Purpose
00-02 created the license architecture (LICENSES.md, per-root LICENSE files, CONTRIBUTING.md). 00-03 created the feature-flag primitive. This plan completes Phase 0 by making the license split machine-verifiable: every source file carries its own SPDX identifier, and a CI workflow catches any import that would breach the community↔enterprise boundary. Completing this plan triggers the mandatory Phase 0 → Phase 1 transition.

## Output
- `scripts/add_spdx_headers.py` — idempotent SPDX header sweep script (handles .py, .ts, .sh, .sql comment syntaxes; skip-list for generated/vendored/migrations/lockfiles)
- `.github/workflows/license-and-imports.yml` — CI workflow: (1) run header sweep in check mode (fail if any file is missing/wrong header), (2) run import-linter contracts to enforce community/core never imports enterprise
- `pyproject.toml` addition — `[tool.importlinter]` root_packages + community→enterprise + core→enterprise forbidden-import contracts
- `docs/learnings/licensing-ci.md` — pattern notes: idempotency, skip-list rationale, import-linter contract schema, negative test instructions
- All existing ~243 source files updated with correct SPDX header in-place
</objective>
